# 《大秦打盗匪助手》安装与使用说明

这是一个**安卓自动挂机 APP**，用于《大秦帝国之帝国烽烟》的"打盗匪 / 讨伐劫匪"玩法。
它通过"无障碍模拟点击 + 模板匹配 + 按钮颜色识别"实现手机上**傻瓜式一键挂机**，无需 root。

> ⚠️ 合规提醒：自动点击可能违反游戏《用户协议》，存在封号风险，请仅在自担风险、
> 且不影响他人游戏体验的前提下使用。

---

## 一、先确认你的手机能用

本 APP 是**安卓 APK**，适用：
- ✅ 华为鸿蒙 **兼容安卓版**（HarmonyOS 4.x / EMUI）—— 你的截图显示玩的是安卓版游戏，多半是这种。
- ❌ 华为 **纯血鸿蒙 NEXT**（HarmonyOS 5/6/7）—— 装不了安卓 APK，此方案不适用。

判断方法：设置 → 关于手机 → HarmonyOS 版本号。显示 4.x / EMUI 即可用。

---

## 二、拿到 APK 文件的三种方法（任选其一）

> 工程里是**源码**，必须编译成 APK 才能安装。下面三种方式都会产出
> `app-debug.apk`，传到手机即可装。

---

### 方法 A（推荐，零本地工具）：GitHub Actions 自动构建

1. 注册一个 GitHub 账号（免费）。
2. 在 GitHub 新建一个**私有**仓库（如 `daqin-helper`）。
3. 把本 `DaQinBanditHelper` 文件夹里的**全部内容**上传到该仓库根目录
   （含隐藏的 `.github` 文件夹，它里有自动构建脚本）。
4. 进入仓库的 **Actions** 页面 → 左侧 "构建 APK" → 点 **Run workflow**。
5. 等几分钟（首次会下载依赖），构建完成后在 **Artifacts** 里下载
   `daqin-bandit-helper-apk.zip`，解压得到 `app-debug.apk`。

### 方法 B（本地，需装 Android Studio）：菜单一键出包

1. 安装 **Android Studio（Hedgehog 2023.1.1 或更新）**。
2. 打开本 `DaQinBanditHelper` 文件夹，等 Gradle 同步完成。
3. 菜单 **Build → Build APK(s)**。
4. 完成后右下角弹出提示，点 **locate** 即可找到 `app-debug.apk`。

### 方法 C（本地命令行）：运行脚本

前提：本机已安装 Gradle 并加入 PATH（或已安装 Android Studio 自带 Gradle）。
双击本文件夹里的 `build_apk.bat`，按提示等待，完成后在
`app\build\outputs\apk\debug\app-debug.apk` 找到文件。

---

## 三、把 APK 传到手机并安装

1. 通过微信文件传输助手 / 数据线 / 网盘 把 `app-debug.apk` 传到手机。
2. 在手机文件管理里点它，按提示安装。
   - 华为会要求"允许安装未知来源应用"，按提示在弹窗里**允许**本次安装。
3. 安装完成后**不要直接打开**，先做下面的权限设置。

---

## 四、手机上必做的权限设置（鸿蒙/EMUI 比原生安卓多两道关）

1. **开 USB 调试**（仅首次安装可能需要）：设置 → 关于手机 → 连点"版本号"7 次 →
   返回 → 系统和更新 → 开发人员选项 → 打开 USB 调试。
2. **开无障碍**：设置 → 辅助功能 → 无障碍 → "已下载的应用"里找到
   **大秦打盗匪助手** → 开启（会弹安全警告，点允许）。
3. **给权限**：设置 → 应用 → 应用管理 → 大秦打盗匪助手 →
   - 权限 → 悬浮窗 / "显示在其他应用上" → 允许
   - 通知 → 允许
4. **🚫 最关键：允许后台运行**（否则挂机几秒就被系统杀掉）：
   设置 → 应用 → 应用启动管理 → 大秦打盗匪助手 → 关闭"自动管理" →
   改为手动管理，并勾选 **允许自启动 / 允许后台活动 / 不允许自动清理**。

## 五、v2.0 改了哪些地方（重要）

这一版是按**你自己录的那段游戏视频**重新还原了操作流程，并修掉了"点击变滑动"的根因。

### 1. 实际操作流程（之前完全搞错了）

旧版本假设"点盗匪 → 弹出面板 → 找讨伐 → 找出征"，但视频里真实的流程是：

```
① 地图上点【盗匪】
     ↓  盗匪旁边弹出一个「放射菜单」：讨伐 / 战斗 / 部队信息
② 点放射菜单里的【讨伐】（或【战斗】）
     ↓  右侧滑出部队面板（主城 / 各分城三列部队）
③ 点右下角蓝色的【全选】
     ↓  按钮文字变成【不选】（说明已经全选好了）
④ 点右下角橙色的【确定】→ 部队出征
⑤ 等战斗结束 → 回到 ①
```

关键点：**「讨伐」按钮的位置是跟着盗匪走的**（以盗匪图标为圆心、半径约 100px 展开），
所以它没法用固定坐标，必须相对盗匪去算 —— v2.0 已经按实测角度算好了。

### 2. 「全选」是个切换按钮

点过之后文字会从**「全选」变成「不选」**。v2.0 会：
- 用**颜色**判断部队面板有没有打开（蓝色按钮出现 = 面板已开，实测 0/2000 个像素，非常干净）；
- 用模板判断按钮当前是"全选"还是"不选"；
- 点完**复查**一次，如果还是"全选"就补点一下，避免把队伍全取消掉。

### 3. "点击滑点"的两个根因（都已修）

| 原因 | 现象 | 修复 |
|------|------|------|
| 旧版点击是"从旁边滑进去"的路径（带随机中途抖动、时长最长 150ms） | 游戏把它当成**拖动/滑动**，于是菜单被划掉、地图被拖跑，看起来就是"点了没反应" | 改成**真正的短按**：按下与抬起在同一像素，时长 38~70ms，没有任何位移 |
| 悬浮窗原来在**右上角**，正好压在右下角的【全选】【确定】按钮上 | 注入的点击全被悬浮窗吃掉 | 悬浮窗移到**左上角**；并且每次点击前会判断目标点是否被浮窗盖住，盖住就临时让浮窗不拦截触摸 |

### 4. 盗匪是限时活动

- APP 里新增 **「盗匪活动时段」**：填开始/结束时间（如 20:00 - 22:30），到点自动等待、不到点不动，
  避免活动外白白扫图。
- **「找不到盗匪等(秒)」**：连续找不到时放慢节奏等刷新（默认 30 秒），不再无休止拖地图。
- 悬浮窗会显示当前是"时段：全天"还是"时段：20:00-22:30"，点一下可临时切换。

### 5. 讨伐 vs 战斗

- 游戏里【讨伐】消耗讨伐令（面板上写着"讨伐令消耗 420/1"），【战斗】不消耗但奖励是普通的。
- APP 和悬浮窗都能切（悬浮窗上那个紫色的按钮）。

## 六、校准与挂机（全部在游戏内完成）

1. 打开本 APP，按顺序点两下：
   - **「⛨ 开启无障碍权限」** → 在系统设置里打开"大秦打盗匪助手"。
   - **「① 授权录屏并启动助手」** → 在系统弹窗里点"开始录制/立即开始"。
     （录屏是识别画面的前提，必须授权；每次重新打开 APP 都要再授权一次。）
   - 状态栏显示 `无障碍：✅ 录屏：✅已授权` 即可。
2. 切到《大秦帝国》游戏，点**左上角悬浮窗**里的 **「校准」**，按屏幕提示依次点 7 步：

   | 步骤 | 做什么 | 可否跳过 |
   |------|--------|----------|
   | 1/7 固定位置 | 在大地图上点一下你的**村庄**（周边搜索的中心） | 可跳过 |
   | 2/7 盗匪图标 | 点任意一个**盗匪**（红褐色小兵那一队） | 否 |
   | 3/7 等级 | 点盗匪名字前面那个**圆形等级数字**（如 60） | 可跳过 |
   | 4/7 讨伐 | 点盗匪旁边弹出的放射菜单里的**【讨伐】**（左上方齿轮图标） | 否 |
   | 5/7 全选 | 部队面板右下角蓝色的**【全选】** | 否 |
   | 6/7 自选队伍 | 想只出某几支就依次点它们，再点「✔ 完成选兵」 | 可跳过 |
   | 7/7 确定 | 右下角橙色的**【确定】** | 否 |

3. 回到悬浮窗点 **「▶ 开始」**，之后全自动；「⏸ 停止」随时停。

> 小技巧：第 6 步跳过 = 每次都"全选"全部可出征部队；第 6 步不跳过 = 每次只点你指定的那几支
> （悬浮窗上的 ＋/－ 可以调出战几支）。

### 悬浮窗上的开关

| 按钮 | 作用 |
|------|------|
| ▶ 开始 / ⏸ 停止 | 启动与暂停挂机 |
| 校准 | 重新走一遍 7 步校准 |
| 自选 2/3 队 | ＋/－ 选本次出战几支队伍（校准第 6 步才可用） |
| 全选：开/关 | 出征前是否自动点蓝色的【全选】 |
| 周边 1000 里 / 全图 | 搜索方式。**周边**模式以"固定位置"为中心，在设定半径内蛇形扫描，不会跑出范围 |
| 等级：不限 / 指定 | 只打校准时标记的那一类盗匪（识别不稳会自动放行，不会卡住） |
| 讨伐 / 战斗 | 放射菜单里点哪个 |
| 时段：全天 / xx:xx-xx:xx | 是否只在活动时段内运行 |

### 搜索范围怎么算

- **搜索半径(里)**：默认 1000，可填 500 / 2000 等。
- **每里=多少像素**：默认 3.0，这是"里"与屏幕像素的换算系数。
  觉得搜的范围太小就调大、太大就调小（例如 5.0）。

### 校准完仍然打不到？

- 「匹配灵敏度」调低到 40~45（画面复杂时更容易匹配上）。
- 悬浮窗挪开一点，别压住游戏里要点的位置（现在默认在左上角，拖标题栏可移动）。

高级设置里可改"每次出征后等待秒数"（按你行军+战斗时间填，默认 20，可加到 30-40）。

## 六·五、关于"防检测 / 拟人化"的说明（务必阅读）

本工具**不包含任何"反检测 / 绕过游戏反作弊"的功能**。游戏的反作弊系统（行为分析、设备指纹、运行环境检测等）属于游戏运营方的保护措施，规避它既违反游戏《用户协议》，也可能触碰相关法规，因此我不会实现对抗检测的代码。

我在脚本里加入的只是**中性的"拟人化操作节奏"**（这是 UI 自动化、无障碍辅助、自动化测试的通用正当做法），APP 内"高级设置 → 拟人化程度"可切换 **轻 / 中 / 强** 三档（默认中）：

| 档位 | 点击落点抖动 | 间隔波动 | 额外停顿概率 |
|------|---------|---------|------------|
| 轻   | ±2px    | ±20%    | 3%         |
| 中   | ±3px    | ±40%    | 8%         |
| 强   | ±4px    | ±70%    | 15%        |

注意：**v2.0 起去掉了"滑入手势"**。旧版那套"从旁边滑进去再点"的路径会让游戏把手势判定成
拖动，导致菜单被划掉、地图被拖跑 —— 这正是"点击没反应"的根源。拟人化现在只体现在
**落点小抖动 + 点击前的随机停顿**上，这两点不会改变手势性质。

**必须如实告知**：这些只能减少"明显机器特征"，**不等于反检测**。游戏服务端若做行为分析（出征频率、在线时长、操作规律性），仍可能识别；而且无论怎么做，使用脚本本身始终违反游戏协议、有封号风险。请仅在自担风险、不影响他人前提下使用，并建议控制时长、不要 24 小时无人值守。

## 七、常见问题

- **悬浮窗按钮点了没反应**：v8 已修复两个根因——① Android 14 下"未授权就进前台"会让无障碍服务被系统打死，
  现在改成**拿到录屏授权后才进前台**；② 以前按钮点击失败时只有通知栏有变化、屏幕上看不出来，
  现在每次点击都有 **Toast + 震动 + 悬浮窗状态文字**。若仍无反应，请确认：
  ① 无障碍是否真的开启；② 录屏是否已授权（状态栏显示"录屏：✅已授权"）；③ 悬浮窗是否被游戏全屏挡住
  （拖标题栏可移动位置）。
- **"点击滑点"、点了菜单自己划掉**：v2.0 已把点击改成真正的短按。如果还出现，请把"拟人化程度"
  调到**轻**，并确认用的是 v2.0 以后的包。
- **"全选"点了之后队伍被清空了**：把悬浮窗上的"全选"关掉，改用校准第 6 步的"自选队伍"。
- **编译报错（如缺 SDK 34）**：把报错发我，我把 `compileSdk/targetSdk` 降到 33。
- **校准浮层/悬浮窗不显示**：个别鸿蒙版本对无障碍浮层有限制，我可换成 `TYPE_PHONE` 方案。
- **总是找不到按钮**：重新校准一次；把"匹配灵敏度"调低到 40-45 试试。
