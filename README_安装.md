# 《大秦打盗匪助手》安装与使用说明

这是一个**安卓自动挂机 APP**，用于《大秦帝国之帝国烽烟》的"打盗匪 / 讨伐劫匪"玩法。
它通过"无障碍模拟点击 + 模板匹配找盗匪"实现手机上**傻瓜式一键挂机**，无需 root。

> ⚠️ 合规提醒：自动点击可能违反游戏《用户协议》，存在封号风险，请仅在自担风险、
> 且不影响他人游戏体验的前提下使用。

---

## 一、先确认你的手机能用

本 APP 是**安卓 APK**，适用：
- ✅ 华为鸿蒙 **兼容安卓版**（HarmonyOS 4.x / EMUI）—— 你的截图显示玩的是安卓版游戏，多半是这种。
- ❌ 华为 **纯血鸿蒙 NEXT**（HarmonyOS 5/6/7）—— 装不了安卓 APK，此方案不适用。

判断方法：设置 → 关于手机 → HarmonyOS 版本号。显示 4.x / EMUI 即可用。

---

## 二、拿到 APK 文件的三种方法（任选其一）

> 工程里是**源码**，必须编译成 APK 才能安装。下面三种方式都会产出
> `app-debug.apk`，传到手机即可装。

---

### 方法 A（推荐，零本地工具）：GitHub Actions 自动构建

1. 注册一个 GitHub 账号（免费）。
2. 在 GitHub 新建一个**私有**仓库（如 `daqin-helper`）。
3. 把本 `DaQinBanditHelper` 文件夹里的**全部内容**上传到该仓库根目录
   （含隐藏的 `.github` 文件夹，它里有自动构建脚本）。
4. 进入仓库的 **Actions** 页面 → 左侧 "构建 APK" → 点 **Run workflow**。
5. 等几分钟（首次会下载依赖），构建完成后在 **Artifacts** 里下载
   `daqin-bandit-helper-apk.zip`，解压得到 `app-debug.apk`。

### 方法 B（本地，需装 Android Studio）：菜单一键出包

1. 安装 **Android Studio（Hedgehog 2023.1.1 或更新）**。
2. 打开本 `DaQinBanditHelper` 文件夹，等 Gradle 同步完成。
3. 菜单 **Build → Build APK(s)**。
4. 完成后右下角弹出提示，点 **locate** 即可找到 `app-debug.apk`。

### 方法 C（本地命令行）：运行脚本

前提：本机已安装 Gradle 并加入 PATH（或已安装 Android Studio 自带 Gradle）。
双击本文件夹里的 `build_apk.bat`，按提示等待，完成后在
`app\build\outputs\apk\debug\app-debug.apk` 找到文件。

---

## 三、把 APK 传到手机并安装

1. 通过微信文件传输助手 / 数据线 / 网盘 把 `app-debug.apk` 传到手机。
2. 在手机文件管理里点它，按提示安装。
   - 华为会要求"允许安装未知来源应用"，按提示在弹窗里**允许**本次安装。
3. 安装完成后**不要直接打开**，先做下面的权限设置。

---

## 四、手机上必做的权限设置（鸿蒙/EMUI 比原生安卓多两道关）

1. **开 USB 调试**（仅首次安装可能需要）：设置 → 关于手机 → 连点"版本号"7 次 →
   返回 → 系统和更新 → 开发人员选项 → 打开 USB 调试。
2. **开无障碍**：设置 → 辅助功能 → 无障碍 → "已下载的应用"里找到
   **大秦打盗匪助手** → 开启（会弹安全警告，点允许）。
3. **给权限**：设置 → 应用 → 应用管理 → 大秦打盗匪助手 →
   - 权限 → 悬浮窗 / "显示在其他应用上" → 允许
   - 通知 → 允许
4. **🚫 最关键：允许后台运行**（否则挂机几秒就被系统杀掉）：
   设置 → 应用 → 应用启动管理 → 大秦打盗匪助手 → 关闭"自动管理" →
   改为手动管理，并勾选 **允许自启动 / 允许后台活动 / 不允许自动清理**。

---

## 五、校准与挂机（只需三步）

1. 打开《大秦帝国》，进入能看到盗匪的大地图。
2. 切到本 APP，点 **「① 一键校准」**：按屏幕提示依次点
   **【盗匪】→【讨伐/战斗】→【出征】**（约 10 秒自动完成，会自动记住位置并截取盗匪模板）。
   - 校准第 2 步点"战斗"= 不消耗讨伐令；点"讨伐"= 消耗令（截哪个就走哪条）。
3. 点 **「▶ 开始打盗匪」**，之后全自动；通知栏或右上角悬浮窗可随时停止。

高级设置里可改"每次出征后等待秒数"（按你行军+战斗时间填，默认 20，可加到 30-40）、
"匹配灵敏度"（画面复杂时调低）。

## 五·五、关于"防检测 / 拟人化"的说明（务必阅读）

本工具**不包含任何"反检测 / 绕过游戏反作弊"的功能**。游戏的反作弊系统（行为分析、设备指纹、运行环境检测等）属于游戏运营方的保护措施，规避它既违反游戏《用户协议》，也可能触碰相关法规，因此我不会实现对抗检测的代码。

我在脚本里加入的只是**中性的"拟人化操作节奏"**（这是 UI 自动化、无障碍辅助、自动化测试的通用正当做法），APP 内"高级设置 → 拟人化程度"可切换 **轻 / 中 / 强** 三档（默认中）：

| 档位 | 点击抖动 | 滑入路点 | 间隔波动 | 额外停顿概率 |
|------|---------|---------|---------|------------|
| 轻   | ±3px    | 0~1     | ±20%    | 3%         |
| 中   | ±7px    | 1~2     | ±40%    | 8%         |
| 强   | ±12px   | 2~3     | ±70%    | 15%        |

这些都只是让操作更像真人手感（坐标随机偏移、滑入手势、随机节奏、偶发停顿），**不是反检测**。

**必须如实告知**：这些只能减少"明显机器特征"，**不等于反检测**。游戏服务端若做行为分析（出征频率、在线时长、操作规律性），仍可能识别；而且无论怎么做，使用脚本本身始终违反游戏协议、有封号风险。请仅在自担风险、不影响他人前提下使用，并建议控制时长、不要 24 小时无人值守。

## 六、常见问题

- **编译报错（如缺 SDK 34）**：把报错发我，我把 `compileSdk/targetSdk` 降到 33。
- **校准浮层/悬浮窗不显示**：个别鸿蒙版本对无障碍浮层有限制，我可换成 `TYPE_PHONE` 方案。
- **点了开始没反应**：多半是无障碍没真正开启或后台被清理，按第四步再确认一次。
